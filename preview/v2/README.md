## 이 플레이에서 실제로 확인한 것

- **콘솔 오류 0** — `window.onerror` / `unhandledrejection` 훅을 설치하고 전 과정을 진행한 뒤 빈 배열 확인.
- **5개 탭 전환** (공식전 · S매치 · 마이팀 · 클럽경영 · 상점) 모두 정상 렌더.
- **선수 상세** — 이름 `유서준 → 강토`, 등번호 `10` 저장 후 피치 라벨·스토리·도트 초상화(등번호 10)에 즉시 반영.
- **역할 지정** — FK를 `최수호 → 강토`로 변경, 피치 배지 갱신 및 CAP·PK 중복 배지 스택 확인.
- **시설 건설** — 미니 연습장 Lv.1(🪙1,400), 훈련 효과 +8%, 다음 업그레이드 🪙2,170 재계산.
- **특훈 콤보** — 슈팅 연습 + 패스 훈련 → `원터치 캐논` 발동, 문동현 Rt.79 → 89, 스킬 해금, 비용 300 → 420 재계산.
- **스카우트 IN/OUT** — 후보 최태양 선택 → 배우진 방출 → 선수단·금화·도감 반영. 동일 조건 갱신(🪙300)으로 4인 리스트 재생성 확인.
- **실제 경기 3판** — 공식전 1:1 무, S매치 1:2 패, 공식전 3:0 승(차도훈 2골·최태양 1골, 도움 강토 2)을 ×3 배속으로 끝까지 진행. 골·경고·태클 이벤트, 하프타임 자동 일시정지와 교체(류동현 OUT → 한무영 IN, 남은 교체 4회) 확인.
- **RESULTS** — 전·후반 스코어, GOALS(전·후반 표기), CAUTIONS, STARTING MEMBER 평점, MATCH STATS, 리그 통산 성적, 보상·승점 반영.
- **자동 저장** — 새로고침 후 3라운드·4경기·영입·훈련·시설 레벨이 그대로 유지(`dot-soccer-v2-save`, v1 세이브와 분리).
- **레이아웃** — 5개 화면 모두 `scrollWidth == clientWidth == 390` (가로 스크롤 없음). 마이팀·S매치는 한 화면(739px)에 겹침 없이 들어가고, 클럽경영·상점은 세로 스크롤.
