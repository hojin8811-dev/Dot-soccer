## 이 플레이에서 실제로 확인한 것

- **콘솔 오류 0** — `window.onerror` / `unhandledrejection` / `console.error` 훅을 페이지 로드 직후 설치하고, 아래 전 과정을 진행한 뒤 배열이 비어 있음을 확인.
- **4개 탭 전환** (클럽 · 스쿼드 · 경기 · 스카우트) 모두 정상 렌더.
- **포메이션 전환** 4-3-3 → 4-4-2 → 3-5-2, 피치 위 좌표 재배치 확인.
- **선수 교체** 후보 전석현 선택 → 피치 ST 조현우 탭 → 스왑, 조직력 83 → 80 변동 확인.
- **스카우트** 일반 600 / 스페셜 2,200 각 1회, 보유 금화 차감과 선수단 17/20 반영.
- **선수 훈련** 김하늘 OVR 79 → 81, Lv.0 → Lv.1, 비용 360 → 480 재계산.
- **실제 경기 1판**: 킥오프 → 패스·드리블·슛·골키퍼 선방 → 골(0:1, GOAL 배너) → 90분 종료 → 무승부 2:2, MVP·평점·승점 +1·보상 210 정산 → 리그 순위표(3위·승점 4) 반영.
- **자동 저장**: 새로고침 후에도 3라운드·2경기 1승 1무·최근 경기·금화가 그대로 유지(`dot-soccer-v1-save`).
- **레이아웃**: 4개 화면 모두 `scrollWidth == clientWidth == 390` (가로 스크롤 없음). 클럽·스쿼드·경기는 `scrollHeight == clientHeight == 740` 로 한 화면에 겹침 없이 들어가고, 스카우트만 세로 스크롤(971px).
